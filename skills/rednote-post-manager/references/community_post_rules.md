# 小红书帖子（笔记）全规则与《社区公约2.0》深耕指南

## 1. 社区底层逻辑：《社区公约2.0》与 CQS 内容质量分
小红书定位为“生活兴趣社区”，《社区公约2.0》核心底线为**“真诚分享、友好互动、有序经营”**，并全面实施 **CQS（内容质量分）体系**：
- **高权重信号**：真人真实体验、具体场景与细节、高信息增量、搜推关键词精准、停留时长与收藏率。
- **低权重/限流信号**：
  - **浓重 AI 味与套路化**：总分总八股文、`首先/其次/总而言之`、大量机械列表 Emoji（`1️⃣ 2️⃣ ✅ 💡 📦`）。
  - **制造对立与虚假人设**：刻意挑起群体对立、用 AI 编造虚假经历或伪造“素人”人设欺骗营销。
  - **纯硬广公告**：直接发“承接XX服务，私信联系”。

## 2. AIGC（AI生成/辅助创作）内容合规红线
- **主动声明义务**：包含 AI 生成图片、视频、音频或大段 AI 合成内容的笔记，发布时**必须手动勾选后台“AI辅助创作”标识**（或正文显著说明）。
- **禁止去标与托管**：严禁使用第三方工具抹除隐式元数据；不主动标识被多模态检测到后会被自动打标并直接**限流不进推荐池**。严禁任何 AI 全自动托管养号、批量洗稿发帖、模拟真人评论私信。

## 3. 重点高危内容领域红线（帖子极易限流/封号）

### 3.1 虚假种草与软广未报备
- **禁止行为**：无真实使用体验的纯抠图/网图拼接、盗图洗稿、虚构测评、通过拉踩排名进行攀附。
- **前后对比图红线**：发护肤/穿搭/身材/功效类前后对比图时，未按规范标注真实拍摄条件（如“原相机、无修图、拍摄时间”）极易被判夸大误导限流。
- **商业合作报备**：带有商业推广性质的合作笔记，未通过官方**蒲公英平台**报备而伪装“素人自来水”，一经查实直接删帖并冻结带货/合作权限。

### 3.2 医疗、健康科普与美妆食品宣称
- **医疗科普高门槛**：医美、疾病诊疗科普对专业认证要求极高（多仅限公立三甲相关医师认证）；普通个人号严禁发布医疗诊疗推荐、制造容貌/健康焦虑、借科普之名引流线下机构。
- **美妆/护肤/普通食品**：普通化妆品不得宣称“祛斑、美白、治疗激素脸、修复炎症”等特殊化妆品/医疗功效；普通食品不得宣称“减肥、降三高、抗癌、调理疾病”。

### 3.3 财经与投资理财（《社区金融生态公约》）
- **八大禁区**：严禁非法荐股（推代码/预测涨跌/抄底牛股）、恶意唱衰或炒作市场走势、保本高收益承诺（`稳赚/躺赚/零风险`）、无资质金融产品推销、违规导流及虚假金融人设。个人分享理财心得必须附带客观风险提示。

## 4. 站外导流全路径零容忍红线
平台通过语义识别 + 图像 OCR + 轨迹监测全链路严查导流：
- **禁用路径**：笔记正文、首图/配图水印、评论区（含大小号唱双簧）、置顶评论、私信、主页简介、甚至**商品快递包裹卡片/售后卡**。
- **禁用词/变体**：微信号、VX、V我、QQ、手机号、二维码、网盘（百度云/夸克等）、外部链接或引导去淘宝/闲鱼/拼多多成交，**谐音与符号拆字（`威信`、`v-x`、`扣扣`）从重处罚**。
- **唯一安全引导**：引导看笔记**左下角官方商品卡片**，或在**小红书店铺客服/群聊**内沟通。

## 5. 笔记违规惩罚梯度
1. **轻度违规**：首次漏标 AI、轻微敏感词或营销倾向 → 单篇笔记仅自己可见 / 限流（0流量） / 扣 1~2 信用分。
2. **中度违规**：多次导流、虚假种草、商业未报备、频繁发同质低质贴 → 账号限流 7~30 天、禁言（48小时/7天）、冻结或清空蒲公英/带货权限。
3. **重度违规**：屡教不改导流、非法荐股/医疗欺诈、批量 AI 矩阵刷量、售卖违禁品 → **永久封号 + 实名身份证/营业执照主体拉黑 + 连带矩阵号一并封禁**。
