# 小红书全平台违禁词库、行业红线词与安全替换指南

小红书执行**“文本语义 + 历史回溯扫描 + 图片 OCR 识别 + 私信/评论行为监测”**四维审核。严禁使用谐音、拼音、符号隔断（如 `v-x`、`zui`、`C*aude`），系统识别后将按“恶意规避”从重处罚。

## 1. 通用广告法极限词与诱导词（全类目适用）
- **绝对化极限词**：`最`（`全网最/最好/最佳/最优/最强/最低/最新/最全/最实用`）、`极致`、`第一（NO.1/TOP1）`、`唯一`、`独家`、`绝对`、`100%`、`永久`、`万能`、`史无前例`、`顶配`、`首选`。
  - *注*：日常时间词如 `最近`、`最后`、`最开始` 正常可用，但广告修饰性质的 `最XX` 必须改为 `很实用`、`个人整理`、`相对稳定`。
- **诱导点击/抢购词**：`秒杀`、`抢爆`、`错过拍断腿`、`点击有惊喜`、`一键三连`、`免费领`、`立即获取`、`闭眼入`、`万人疯抢`。
- **未证实效果/量化承诺词**：`包过`、`包学会`、`稳赚不赔`、`月入过万`、`零基础暴富`、`暴降80%`、`省下70%`、`成片率翻倍`、`远超这份资料`、`彻底解决`、`彻底改变`、`无效退款`。

## 2. 站外导流封号红线词（笔记/评论/私信/包裹卡全禁）
- **严禁出现**：`微信`、`威信`、`VX`、`V我`、`+V`、`加v`、`QQ`、`扣扣`、`手机号`、`二维码`、`扫码`、`网盘`、`百度云`、`夸克`、`戳链接`、`私信发`、`加群`、`闲鱼`、`淘宝`、`某宝`、`拼多多`、`看主页简介`、`好评返现`。

## 3. 重点行业专项禁用词

### 3.1 “三品一械”、医美与食品美妆词
- **医疗器械/药品（禁售/禁推）**：`械字号`、`医用冷敷贴`、`隐形眼镜`、`美瞳`、`护理液`、`处方药`、`抗生素`、`注射器`、`呼吸机`、`制氧机`、`自制中药`、`蓝帽子`、`特医食品`、`婴幼儿奶粉`。
- **禁止出现的医疗宣称词**：`根治`、`治愈`、`药到病除`、`消炎`、`杀菌`、`激素脸`、`降三高`、`抗癌`、`防癌`、`祛斑美白`（普通化妆品无特证禁用）、`减肥瘦身`（普通食品禁用）。

### 3.2 财经/金融违规词
- **严禁出现**：`非法荐股`、`荐股`、`牛股`、`内幕消息`、`抄底必涨`、`稳赚`、`保本`、`躺赚`、`无风险高收益`、`翻倍收益`。

### 3.3 仿品版权与违禁商品词
- **仿品洗白词**：`高仿`、`精仿`、`A货`、`超A`、`复刻`、`原单`、`尾单`、`厂货`、`渠道货`、`1:1`、`剪标`、`水货`。
- **其他禁售词**：`电子烟`、`烟弹`、`香烟`、`活体宠物`、`管制刀具`、`情趣内衣`、`代写`、`代考`、`外挂`、`刷单`、`好评返现`。

## 4. 个人店超范围词 & 海外 AI 工具安全代号

### 4.1 个人店超范围服务词（在 `--mode shop` 下强拦截）
- **严禁出现**：`远程安装`、`代安装`、`代装`、`远程协助`、`远程控制`、`向日葵`、`ToDesk`、`1对1技术调试`、`有偿咨询/调试服务`、`技术劳务`、`部署到服务器`。
- **安全重构**：改为 **`电子图文配置手册` + `标准配置模板` + `购买资料附带售后答疑`**。
- **版权/账号/接口词（否定句也不要出现！）**：`破解`、`盗版`、`激活码`、`注册机`、`账号`、`独享号`、`合租`、`代充`、`额度`、`API接入`、`Token售卖`、`VPN`、`科学上网`、`梯子`、`翻墙`。
