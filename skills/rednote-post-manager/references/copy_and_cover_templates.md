## 1. 封面视觉规范（拒绝丑陋暗黑赛博风）
- **整体风格要求**：坚决摒弃“暗黑霓虹渐变背景 + 发光胶囊卡片”的廉价营销风！
- **推荐高级感风格**：
  1. **暖白网格手账/瑞士编辑风**：浅米白网格底（`#F4F1EA`）+ 黑体粗字 + 荧光黄/橙色重点高亮条 + 简约白卡或深灰终端窗口卡片。
  2. **真人实拍混合风**：在小红书笔记第 2~4 张配图加入电脑/手机实拍、局部打码的 PDF 目录或终端界面图，提升真实度。
- **双场景尺寸区分**：
  - **帖子（笔记）封面**：**3:4 竖版**（如 `900 × 1200 px`），标题像真实用户吐槽/经验贴（如 `配置反重力 / CC 老是报错？这 4 个坑查完基本能通`）。
  - **个人店商品主图**：**1:1 正方形**（如 `1200 × 1200 px`），必须突出 **“电子手册 / 配置模板 + 售后配置答疑 + 平台自动发货”**，绝不能出现“代装/远程/服务劳务”。

## 2. 帖子（笔记）模板：去 AI 味“活人感”写法
> 避坑核心：**禁止** `总而言之/不仅如此/保姆级干货赋能` 等 AI 八股文，**禁止**大量 `1️⃣ 2️⃣ ✅ 💡 📦` 排列，像真人在朋友圈或论坛跟同行聊踩坑一样自然：

### 示例模板（踩坑分享 + 挂车自然带货）
**标题**（痛点共鸣/经验分享）：
`配置反重力 / CC / O社CLI 老报错？这几个环境坑查完基本能通📝`

**正文**：
```text
最近好几个做开发的朋友问我，想试试反重力或者 CC、O社家的命令行工具，结果光是配本地环境就卡了一晚上：不是终端一直提示 command not found，就是装依赖满屏红字报错，好不容易弄好，配完 DS 或哈基米模型又连不上。

把几个最容易踩的坑理了一遍，大家按顺序查一下基本就能跑通：
1. 环境变量没刷进去：Mac 上配完记得检查一下 zshrc 路径对不对，Windows 尽量别放在带中文或空格的目录下。
2. 运行环境版本冲突：不少命令行工具对 Node 或 Python 版本要求比较卡死，老版本直接跑容易报依赖错误，先用版本管理工具切到推荐版本再试。
3. 配置文件格式写错：对接 DS 或哈基米这类官方模型时，多半是 YAML/JSON 缩进多了一个空格，或者请求地址末尾多带了一层路径导致的。
4. 端口与本地权限拦截：如果一直卡在请求超时转圈，排查一下终端本身的端口监听状态以及系统防火墙拦截权限。

按上面几步查完如果还是有红字报错，可以把报错截图发在评论区，我看到都会顺手帮看一眼卡在哪；不想自己一点点折腾查错的，也可以点左下角小卡片拿我整理好的图文手册和配置模板（含售后答疑）。

#AI编程 #开发环境配置 #反重力 #程序员日常 #Mac开发 #效率工具
```
