# 小红书个人售卖（个人店）全品类规则与合规运营指南

## 1. 个人店的定位、准入与核心权限边界
- **基础属性**：仅凭身份证实名及人脸核验即可开店（先发品后交保证金模式），**但无法投放薯条、聚光等商业付费推广**，高度依赖笔记自然搜推流量。
- **权限硬限制**：个人店开放的类目极窄，高风险、需强资质或品牌授权的类目**完全不对个人店开放**。一旦超范围上架，直接触发下架、扣分甚至清退。

---

## 2. 小红书个人店全面禁售 / 限售品类清单（踩中必封）

### 2.1 “三品一械”与医疗健康高压区（最严禁令）
- **药品与医疗器械（个人店绝对禁售）**：
  - OTC 药品、处方药、精制中药材、偏方散剂。
  - 二类/三类医疗器械：**隐形眼镜/美瞳、隐形眼镜护理液、械字号面膜/医用冷敷贴、注射器、家用制氧机/无创呼吸机、医用超声仪**。
- **保健与特殊食品**：
  - 带有“蓝帽子”标志的膳食营养补充剂/保健食品（严格受控/禁推）。
  - **特殊医学用途配方食品、全类目婴幼儿奶粉（牛奶粉/羊奶粉）**。
- **医美服务**：无医疗执业资质的个人店及买手严禁上架任何医美诊疗项目。

### 2.2 无资质美妆个护与全球购跨境品
- 普通个人店严禁分销或上架无品牌授权、无国产备案/质检报告、无报关单的**进口水货、分装小样或大牌美妆**（“全球购”已全面转向定向邀约制，个人店无权限）。
- 普通洗护/化妆品详情页严禁出现医疗化、美白祛斑、抗炎祛痘根治功效宣称。

### 2.3 普通食品合规红线
- 无食品经营许可/三无散装自制食品不可随意上架；正规预包装普通食品在标题和详情中**绝对禁止出现“减肥、降三高、抗癌、治病、养生调理”等功效宣称**。

### 2.4 其他全平台绝对禁售红线
- 活体宠物（猫、狗、异宠等）。
- 烟草、卷烟、电子烟及烟弹、槟榔等。
- 计生用品、情趣内衣及低俗擦边物品；管制刀具、易燃易爆危险品。
- 假冒伪劣与侵权仿品（禁用 `高仿/复刻/原单/1:1/剪标`）。
- 灰产虚拟物：虚拟货币、游戏币/外挂/代练、刷单兼职、无资质借贷、代写代考、各类网络账号买卖、海外 AI 账号/API 额度/科学上网服务。

## 3. 个人店如何合规经营【电子资源 / 技能教程】类目

### 3.1 个人店卖“技术服务 / 软件配置”的致命死穴
- 小红书将 `软件开发`、`IT运维调试`、`软件代安装`、`远程协助`、`专业技术咨询` 划归**企业店资质范围**。
- **个人店直接上架“远程安装 / 代装 / 1对1有偿技术调试”**，即便规避了敏感词，也会因**“类目不符 / 无企业资质超范围经营 / 远程安全风险 / 无物流交付凭证”**被千帆系统下架！

### 3.2 唯一安全合规的“电子资源换壳闭环”
1. **类目选择**：申请并挂靠 **`电子资源`** 一级类目（涵盖原创学习笔记、办公模板、配置指南、设计素材；注意开通该类目通常有账号实名、历史笔记数、粉丝数或站外流水门槛及保证金要求，以千帆后台实时门槛为准）。
2. **禁止盗版搬运**：严禁打包转售未经授权的商业机构录播课、整本盗版 PDF 或他人网盘合集；必须基于自身实操进行**原创或结构化二次整合**。
3. **商品主体包装**：
   - 将商品主体定性为：**《图文配置手册（PDF）+ 标准配置模板包（YAML/JSON）+ 高频报错自查清单》**。
   - **协助排错包装为“售后服务”**：在详情页注明 `购买资料后若按手册操作仍遇到本地报错，可在店铺客服窗口发送截图，提供附带的使用答疑支持`。
4. **虚拟自动发货闭环**：千帆后台**必须开启“虚拟自动发货”**，真正上传 PDF/ZIP 数字交付文件，确保平台系统校验存在完整数字货品交付。

## 4. 个人店发货、履约与客诉防封底线
- **严禁虚假发货与低价引流**：禁止上传空包单号、无更新物流或发小礼品占位；禁止 `0.01元 / 1元` 钓鱼低价引流。
- **沟通阵地与快递卡红线**：所有售前售后沟通必须在**小红书千帆客服系统**完成留证，**严禁在发货包裹里塞写着微信/QQ/返现二维码的售后卡/好评卡**！
- **防止客诉率拖垮权重**：虚拟电子资料易起“货不对板”争议，详情页必须客观陈述包含的文件页数、格式、适用版本及不支持无理由退换说明，避免高纠纷率触发店铺清退或扣除保证金。
